# resource-aware-workshop.github.io

Homepage for the **NeurIPS 2026 Workshop on Resource-Aware Agentic AI**.

Static single-page site, served by GitHub Pages from the root of the default branch.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Relative asset paths break under `file://`, so use the server.

## Deploy

Push to `main`. There is no build step: the committed files are what gets served.
